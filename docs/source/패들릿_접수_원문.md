## 게시물 · 패들릿 제출
### 재고실사 비효율 개선

① 직무·소속 : (회사명 생략) 경영관리팀
② 해결하고 싶은 현안 1건 : 재고실사 Start-End 시스템 구현. 회계감사를 위해 재고실사에 참여했다가 자재관리팀 현장 재고실사의 비효율을 발견. 작업 순서: 작업 배정 → 재고 시스템 수량 및 현장 확인 → 차이 확인 → 사유 확인 → 취합 → 보고서 작성. ERP에서 다운로드받은 엑셀(데이터 01)을 새 시스템에 업로드하는 것부터 작업지시를 출발하고, 휴대폰으로 접속하여 현장에서 편하게 재고실사 기록, 취합이 실시간으로 진행, 보고서는 창고별·자재유형별·자재타입별 등 다양한 방식으로 BI, 최종 보고서(데이터 06)를 만들고 싶음.
③ 보유 데이터 유형 : ERP에서 다운 받은 재고 Data(Excel)
④ 기대 산출물 : 작업배정 시스템화, 현장 실시간 재고수량 및 사유 입력을 통한 재고 …(원문 잘림)

## 강사 요청 댓글 (요지)

자료 요청:

1. ERP 에서 내려받은 재고 엑셀 견본(값을 가린 사본) — 실제 열 이름과 순서
2. 창고·구역과 담당자 목록, 「자재유형」「자재타입」이 ERP 의 어느 칸인지
3. 차이 허용 기준(수량 %·금액)
4. 수량 근거 사진이 필요한 경우와 회사 휴대폰 촬영 가능 여부
5. 실시간 공유 방식(회사 서버만 / 외부 클라우드 허용), 창고 휴대폰 인터넷, 보고서(pptx) 양식

진행 범위: 1차는 작업지시(기준 일자·시각) → 휴대폰 현장 입력 → 결과 파일 합치기 → 차이대사 → 창고별·자재유형별·자재타입별 BI → 버전 있는 결과 보고서. 기기 간 실시간 공유는 회사 허용 방식을 정한 뒤 2단계.
